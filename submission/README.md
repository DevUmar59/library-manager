# submission/

Put your Assessment 1 files here before running `python finalize.py`:

- `demo_video.mp4` – the demo video (any .mp4 / .mov / .mkv name works)
- `A1_Technical_Report.pdf` – the technical report (.pdf or .docx)

Everything in this folder except this README is ignored by Git, so large video
files and the report are never pushed to the public repository.
